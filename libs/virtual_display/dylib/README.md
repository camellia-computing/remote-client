# virtual display

Virtual display may be used on computers that do not have a monitor.

[Development reference](https://github.com/pavlobu/deskreen/discussions/86)

## windows

Windows provides [Indirect Display Driver Model](https://learn.microsoft.com/windows-hardware/drivers/display/indirect-display-driver-model-overview).

This library uses the bundled Camellia Remote indirect-display driver. Release builds must verify the driver digest and signature together with the desktop package.

- [x] 19041
- [x] 19043
